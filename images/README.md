```

│   │   ├── wednesday/

│   │   └── friday/

│       └── (те же дни недели)
├── site/                     фотографии самого сайта
│   ├── about/                блок «О компании»

```

## Правила имён

**Фото блюда:** `menu/<категория>/<день>/<slug названия>.webp`

Slug — транслитерация названия блюда в нижнем регистре: пробелы, запятые и
скобки заменяются на дефис.

| Название в меню | Файл |
|---|---|
| Суп молочный манный с маслом сливочным | `menu/breakfasts/monday/sup-molochnyy-mannyy-s-maslom-slivochnym.webp` |
| Рулет из омлета с мясом | `menu/breakfasts/monday/rulet-iz-omleta-s-myasom.webp` |
| Хлеб белый, чёрный | `menu/breakfasts/monday/khleb-belyy-chernyy.webp` |

Слаг ограничен 60 символами и обрезается по границе слова. Если в одной
папке оказываются два разных блюда с одинаковым названием, второму
добавляется суффикс `-2`, `-3`.

**Фото сайта:** `site/<раздел>/<что-на-фото>.webp` — имя описывает содержимое,
а не исходный файл (`about-1`, `step-2-place-order`, `delivery-club`).

## Оригиналы

Рядом с каждым `.webp` лежит исходный `.jpg`/`.png` с тем же именем.
Он не отдаётся браузеру, но нужен, чтобы пересобрать WebP в другом размере:

```bash
python tools/convert-images.py   # пережмёт все JPG/PNG в WebP (max 1200px, q80)
```

## Задел под автоподбор фото к меню

Когда появится загрузка меню, сопоставление делается по слагу названия:

1. название блюда → `slugify()` (транслитерация + дефисы);
2. категория → `breakfasts` / `lunches` / `complex-lunches` / `banquets`;
3. день → `monday` … `sunday`;
4. ищем `menu/<категория>/<день>/<slug>.webp`, при промахе — нечёткое
   совпадение по началу слага;
5. загруженное фото конвертируем в WebP и кладём по этому же пути.

Скрипт `tools/reorganize-images.mjs` содержит готовые словари `CATEGORY`,
`DAY` и функцию `slugify()` — их можно переиспользовать в загрузчике.

## Что в `_unused`

Файлы, которые не упоминаются ни в разметке, ни в `js/data.js`. Удалять их
можно, но сначала стоит посмотреть глазами:

- `7e96335e…`, `df390e72…` — фото обедов, не попавшие в меню;
- `White_bread_black_bread` — вариант фото хлеба;
- `delivery-club` — альтернативный логотип партнёра.
