# Инструменты

Все скрипты запускаются из корня проекта.

## Изображения

| Скрипт | Что делает |
|---|---|
| `convert-images.py` | Пережимает все JPG/PNG из `images/` в WebP (≤1200px, q80) |
| `reorganize-images.mjs` | Раскладывает фото по `menu/<категория>/<день>` и `site/<раздел>`, правит пути в HTML и `data.js`. Содержит словари `CATEGORY`, `DAY` и `slugify()` |
| `make-assets.py` | Иконки (favicon, apple-touch-icon, 512) и OG-картинка из `logo.png` |
| `render-logo.mjs` | Рендерит SVG-логотип из `index.html` в прозрачный PNG через headless Edge |

## SEO

| Скрипт | Что делает |
|---|---|
| `build-seo.mjs` | Проставляет description, canonical, OG/Twitter, иконки, JSON-LD, preload; генерирует `sitemap.xml` и `robots.txt`. Повторный запуск перезаписывает блок между `<!-- seo:start/end -->` |
| `inspect-seo.mjs` | Показывает title, наличие description и h1 по всем страницам |
| `page-weight.mjs` | Считает вес страниц (было → стало), проверяет JSON-LD и дубли мета-тегов |

## Проверки

| Скрипт | Что делает | Нужен `danger-full-access` |
|---|---|---|
| `linkcheck.mjs` | Все ссылки и ассеты: существование + точный регистр (важно для Linux на Pages) | нет |
| `mobile-audit.mjs` | 13 страниц × 7 ширин: переполнение, элементы за экраном, размеры тап-зон. `--shots` — со скриншотами | да |
| `probe.mjs` | Геометрия и вычисленные стили конкретных селекторов на заданной ширине | да |
| `shot.mjs` | Скриншот страницы или отдельного элемента на заданной ширине. Пятый аргумент `nojs` — снять без JavaScript | да |
| `check-ui.mjs` | Проверка выпадающих списков (поиск, выбор почты) в мобильном вьюпорте | да |
| `check-reviews.mjs` | Отзывы: 8 карточек и кнопка на десктопе, бесконечная карусель на телефоне. Подменяет ответ API 12 отзывами | да |
| `check-header.mjs` | Липкая шапка на 390/768/1440 и то, что якорные ссылки не прячут заголовки под ней | да |
| `check-qty.mjs` | Счётчик «добавлено в корзину» в карточке меню: размеры, фон, рамка, выход за карточку | да |
| `check-favorites.mjs` | Избранное: стили счётчика и клики + / − / × (товар должен исчезнуть из избранного) | да |
| `analyze-images.mjs` | Диагностика: какие фото используются, какие нет, дубли названий блюд | нет |

Браузерные скрипты не запускаются внутри песочницы: Chromium не может открыть
named pipes. При запуске через агента нужен режим `danger-full-access`.

## Порядок при обновлении меню

1. Положить фото в `images/menu/<категория>/<день>/` с именем-слагом.
2. `python tools/convert-images.py` — получить WebP.
3. Поправить `js/data.js` (поле `image`).
4. `node tools/linkcheck.mjs` — убедиться, что все пути существуют.
5. `node tools/mobile-audit.mjs --shots` — проверить вёрстку.
